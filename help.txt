Kilo Help
=========

Normal mode commands:
  i     - switch to insert mode
  o     - open new line below and insert
  :help - open this help
  :w    - save file
  :q    - quit
  :s/pat/repl/   - substitute all matches of pat with repl (regex)
  /pat  - search for pattern using regex
  n     - go to next search match
  N     - go to previous search match
  Tab   - autocomplete keywords when in insert mode

Buffers and tabs:
  :e <file>  - open file in a new buffer/tab
  :bn        - next buffer
  :bp        - previous buffer
  :bd        - close current buffer
  :help      - open this help. Use :bd or Ctrl+p/Ctrl+n to return.

Saving the help buffer is disabled.

Movement keys in normal mode:
  h - left, j - down, k - up, l - right
  w - next word, b - previous word, e - end of word, $ - end of line
